Student Query Management System

Students ask questions, an LLM drafts an answer, a teacher approves or edits it, and the final answer goes back to the student, all through a web server written from scratch in C.

Where a question goes

  1. PENDING_LLMQuestion received
  2. LLM_ANSWEREDDraft from the LLM
  3. TEACHER_APPROVED / EDITEDTeacher reviewed
  4. DELIVEREDAnswer sent to the student
