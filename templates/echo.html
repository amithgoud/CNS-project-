Echo

The web version of a TCP echo server: whatever you send, the server sends back. Try both forms and compare how the message reaches the server.

{{{result}}}

Send with GET

The message is added to the URL as /echo?message=.... Look at your address bar after sending.

Send with POST

The message travels in the request body. The URL stays clean, and the server reads exactly Content-Length bytes after the headers.

Try typing <b>bold</b>: it comes back as plain text, because the server HTML-escapes everything a user sends before putting it in a page.
